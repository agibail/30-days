A one-tap tracker for how many cigarettes I smoke in a day. [Open the app](days/day-01/site/index.html)

- Big **+1** button, undo, and remove any entry from today's list
- "Add one I forgot" to log at an earlier time
- Time since the last one, yesterday's total, how many I'd had *by this time* yesterday, 7-day average
- Bar chart of the last 14 days, with an optional daily limit line
- Data stays on the phone (localStorage), nothing is uploaded. Export CSV anytime.

**On iPhone:** open the app in Safari → Share → *Add to Home Screen* so it opens like an app.
